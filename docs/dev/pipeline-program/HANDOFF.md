## How the work was run
One owner agent (pstack:poteto-agent, own git worktree) per PR, spec in Gherkin first, whole suite + both plugin validations + CLI-level live lanes, an independent read-only review, then a PR. Every PR that touches a protection (tripwire, guard, approvals, locks) got 4 to 6 rounds of automated security review that kept finding real gaps. Lesson recorded in the plan: prefer deleting a forgeable mechanism over patching it; when a reader is unsure, fail closed. Merge each PR with `gh pr merge N --squash --delete-branch` when all checks pass (the project's `.claude/settings.local.json` allow rule `Bash(gh pr merge:*)` makes this possible; it is git-ignored, recreate it on the new machine). `main` has branch protection requiring the check `all-checks`; auto-merge is on; the secret `PINS_TOKEN` (fine-grained PAT with Contents, Pull requests, Workflows write) drives the weekly language-version PR.
